# Submission Guidelines

## What to submit

* A public (or shared) GitHub repository link containing your project code.

* A live deployed app link (Streamlit Community Cloud).

## What your repository should include

* app.py and prompts.py (or your renamed equivalents)

* requirements.txt

* A .streamlit/secrets.toml.example template \- never your real secrets.toml

* A .gitignore that excludes .streamlit/secrets.toml, venv/, and \_\_pycache\_\_/

* A short README: what your app does, and how to run it locally

## Evaluation criteria

* Functionality (40%) \- does the app run, and does the core flow (input → AI response → WhatsApp / Telegram / Email summary) work end to end?

* Prompt design (20%) \- is the system prompt scoped sensibly to the app's stated purpose?

* Code quality (20%) \- is the code organized, readable, and free of committed secrets?

* Creativity / polish (20%) \- thoughtful extensions, a clear README, a nice user experience.

*Before submitting, double-check that .streamlit/secrets.toml (with real API keys) is not committed to the repository \- only secrets.toml.example should be tracked.*
